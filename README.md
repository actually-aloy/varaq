# Varaq (ورق)

A quiet, minimalist PDF reader.

Continuous & two-page layouts, smooth zoom, thumbnails & outline, full-text
search, highlights / area marks / Markdown text boxes with undo, bookmarks,
light / sepia / dark themes (with real dark pages), a command palette, drag
& drop, password-protected files, and full English + Persian (فارسی) / RTL
support.

## Getting it

Grab the latest .zip from the [Releases](../../releases) page,
extract, double-click it, and you're reading. No installer, no setup.

## Saving & where things live

Pressing `Ctrl+S` writes your annotations into the PDF itself, next to a
small private copy so everything stays editable if you reopen it in Varaq.
Until you save — and for things a plain PDF annotation can't hold
(bookmarks, your last page, zoom, dark-page preference…) — Varaq keeps its
own small folder next to the app:

```
Varaq_data/
  state.json       settings, recent files, toolbar state, window position
  docs/            per-PDF reading position, bookmarks, not-yet-saved marks
```

Nothing is ever written next to your PDFs, other than the PDF you
explicitly save into.

# ورق (Varaq)

یه PDF reader ساده و بی‌حاشیه.

چیدمان پیوسته یا دوصفحه‌ای، زوم نرم، تامبنیل و فهرست مطالب، جستجوی تمام‌متن، هایلایت کردن و مشخص کردن ناحیه و جعبه‌متن مارک‌داون (با Undo کامل)، بوکمارک، تم روشن / سپیا / تاریک (با صفحات واقعاً تاریک، نه فقط رنگ معکوس)، command palette، کشیدن و رها کردن فایل، باز کردن فایل‌های رمزدار، و پشتیبانی کامل از فارسی و راست‌به‌چپ.

## دریافت

آخرین نسخه رو از صفحه‌ی [Releases](../../releases) به‌صورت zip بگیر، extract کن، دوبار کلیک کن روش. نه نصبی لازمه نه تنظیماتی.

## ذخیره‌سازی و اینکه چی کجا می‌مونه

با `Ctrl+S` هایلایت‌ها، ناحیه‌های مشخص‌شده و جعبه‌متن‌هات مستقیم تو خود فایل PDF نوشته میشن، یه کپی خصوصی هم کنارش نگه داشته میشه که اگه دوباره تو ورق بازش کردی، همه‌چیز قابل ویرایش بمونه. تا قبل از Save — و برای چیزایی که یه annotation ساده‌ی PDF اصلاً جا نداره (بوکمارک‌ها، آخرین صفحه‌ای که بودی، میزان زوم، تنظیم صفحات تاریک...) — ورق یه پوشه‌ی کوچیک کنار خودش نگه می‌داره:

```
Varaq_data/
  state.json       تنظیمات، فایل‌های اخیر، وضعیت نوار ابزار، موقعیت پنجره
  docs/            موقعیت خوندن هر PDF، بوکمارک‌ها، annotation های هنوز ذخیره‌نشده
```

هیچ‌وقت چیزی کنار خودِ فایل‌های PDFت نوشته نمیشه، به‌جز همون فایلی که خودت صراحتاً توش Save می‌کنی.
